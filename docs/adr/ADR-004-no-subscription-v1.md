# ADR-004 — İlk sürümde abonelik yok

**Durum:** Kabul edildi

İlk sürümde uygulama içi abonelik, ödeme, periyodik tahsilat, paket limiti, otomatik lisans yenileme veya zorunlu online lisans doğrulama bulunmaz. Ticari lisans/kurulum sözleşmesi uygulama dışındadır. İleride abonelik eklenmesi ayrı ürün fazı ve ayrı modül kararı olacaktır.
