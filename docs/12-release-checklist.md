# 12 — Sürüm ve Müşteriye Teslim Kontrol Listesi

## Ürün
- [ ] Mobil uygulama ve web panel sürüm numarası uyumlu.
- [ ] Kurulum sihirbazı veya ilk admin oluşturma adımı çalışıyor.
- [ ] Proje, günlük rapor, görev, puantaj, stok, gider ve hakediş akışları test edildi.
- [ ] Offline kayıt ve senkronizasyon test edildi.
- [ ] Rol ve proje bazlı yetki testleri tamamlandı.
- [ ] PDF/Excel dışa aktarma çıktıları kontrol edildi.

## Güvenlik
- [ ] Production HTTPS aktif.
- [ ] Varsayılan credential yok.
- [ ] Secret scanning ve dependency audit temiz veya riskler belgeli.
- [ ] DB dış erişime kapalı.
- [ ] Backup ve restore testi yapıldı.
- [ ] Audit log ve erişim politikaları doğrulandı.

## Performans ve kalite
- [ ] Lint, typecheck, test ve build başarılı.
- [ ] Kritik endpoint p95 ölçümleri kayıtlı.
- [ ] Büyük fotoğraf ve uzun liste test edildi.
- [ ] Android gerçek cihaz saha testi yapıldı.
- [ ] Hata ve çakışma ekranları anlaşılır.

## Ticari teslim
- [ ] Müşterinin tek seferlik kullanım lisansı/sözleşmesi ayrı dokümanda.
- [ ] Kurulum, domain, sunucu ve yedekleme sorumlulukları yazılı.
- [ ] Kullanıcı eğitimi ve kısa kullanım kılavuzu teslim edildi.
- [ ] Kaynak kod / build / bakım kapsamı sözleşmeye göre net.
- [ ] Uygulama içinde abonelik veya ödeme akışı bulunmadığı doğrulandı.
