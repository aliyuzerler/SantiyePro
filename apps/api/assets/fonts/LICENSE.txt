# DejaVu Sans / DejaVu Sans Bold — bu dizindeki kopyalar

Bu fontlar, ŞantiyePro PDF dışa aktarmasında Türkçe karakter (ğ, ş, İ, ı)
desteğiyle metin çizmek için gömülür (Faz 10, docs/05).

- Kaynak: https://dejavu-fonts.github.io/
- Lisans: Bitstream Vera + public domain katkıları (iz aşağıda).
- Yeniden dağıtım Bitstream Vera lisansı tarafından serbestçe izinlidir;
  font yazılımı "as is" sağlanır.
