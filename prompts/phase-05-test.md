# Phase 05 — Test Promptu

Günlük rapor ve medya testleri:
- Taslak oluşturma/güncelleme/gönderme/onay/red akışı.
- Onay sonrası revizyon ve eski içeriğin korunması.
- Yetkisiz proje raporuna erişim.
- MIME spoofing, aşırı dosya boyutu, path traversal, sahte media ID testleri.
- Signed URL süresi ve kullanıcı/proje erişim kontrolü.
- EXIF GPS metadata politikasının uygulandığı.
- Fotoğraf upload başarısızlığında rapor metni korunuyor mu?
- Birden fazla görsel thumbnail ve galeri performansı.
- Web/mobil loading, empty, error ve offline form davranışı.

Gerekli entegrasyon testlerini ekle; lint/typecheck/test/build çalıştır. `docs/test-reports/phase-05.md` raporu oluştur.
